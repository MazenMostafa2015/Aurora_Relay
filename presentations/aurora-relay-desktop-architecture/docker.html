06 / SANDBOX INTEGRATION
REQUIRED FOR CODE EXECUTION

Isolation is a prerequisite,
not an optimization.

Aurora Relay enables the code executor only after Docker proves that a healthy server is reachable. A CLI binary alone is not enough.

01 / PROBE
docker version

Ask the local Docker client for a live server response.

02 / GATE
Sandbox ready

Enable the container executor with its resource, network, and filesystem policy.

→OTHERWISE
03 / FAIL-CLOSED
Execution disabled

Keep code tools unavailable. Never substitute a host shell.

BOUNDARY
CONTROLS
No TCP exposureNever ask users to expose the Docker daemon over a public or unauthenticated socket.
No broad mountsDo not grant unrestricted host filesystem access to an execution container.
Explicit policyKeep CPU, memory, time, network, and file boundaries enforced by the sandbox layer.
Auditable stateRecord runtime health and tool availability so the UI explains why execution is unavailable.
